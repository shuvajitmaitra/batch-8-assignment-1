# TypeScript Assignment 1

A TypeScript project featuring practical problem solutions and conceptual documentation on core TypeScript features and OOP principles.

## Blog Articles

- **[How Access Modifiers Work in TypeScript OOP](./access-modifiers.md)** - Detailed explanation and examples of access modifiers (`public`, `private`, `protected`, `readonly`).
- **[Type Aliases vs Interfaces in TypeScript](./type-vs-interface.md)** - Comparison highlighting differences, features, and when to choose one over the other.

## Project Structure

- **[`solutions.ts`](./solutions.ts)** - TypeScript implementations covering functions, union types, tuples, generics, OOP classes, and asynchronous logic.
- **[`access-modifiers.md`](./access-modifiers.md)** - Detailed explanation and examples of access modifiers (`public`, `private`, `protected`, `readonly`).
- **[`type-vs-interface.md`](./type-vs-interface.md)** - Comparison between Type Aliases and Interfaces, highlighting differences and use cases.
- **`tsconfig.json`** - TypeScript compiler configuration.
- **`index.html`** - Web page for running and testing the solutions in a browser.

## Getting Started

1. **Compile TypeScript**:
   ```bash
   npx tsc
   ```
   *(or `npx tsc -w` to watch for file changes)*

2. **Run the Project**:
   Open `index.html` in your web browser.
