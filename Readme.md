# TypeScript Assignment 1

A TypeScript project featuring practical problem solutions and conceptual documentation on core TypeScript features and OOP principles.

## Project Structure

- **`solutions.ts`** - TypeScript implementations covering functions, union types, tuples, generics, OOP classes, and asynchronous logic.
- **`access-modifiers.md`** - Detailed explanation and examples of access modifiers (`public`, `private`, `protected`, `readonly`).
- **`type-vs-interface.md`** - Comparison between Type Aliases and Interfaces, highlighting differences and use cases.
- **`tsconfig.json`** - TypeScript compiler configuration.
- **`index.html`** - Web page for running and testing the solutions in a browser.

## Getting Started

1. **Compile TypeScript**:
   ```bash
   npx tsc
   ```
   *(or `npx tsc -w` to watch for file changes)*

2. **Run the Project**:
   Open `index.html` in your web browser.
